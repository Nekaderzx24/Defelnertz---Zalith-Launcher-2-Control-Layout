# Defelnertz - Zalith Launcher 2 Control Layout
A simple control layout for Zalith Launcher 2

### ⚠️ Important DPI Note:
This control layout is specifically designed for a **DPI of 600–612**. If your device uses a lower DPI, the text on the buttons may appear too large.

**How to fix it:**
Go to:  
`Editor Menu` > `Control Display List` > `Transparent & Other` > Adjust the text size to your preference.

---
### 📥 How to Install:
1. Download the `.json` file from the assets below.
2. Import the layout into your Zalith Launcher.
3. Enjoy your game!#
